# 내 목소리 (My Voice) — 지원

말장애(구음장애)가 있는 사람이 자기 목소리로 음성인식 학습 데이터를 만들고, 나만의 음성인식 모델을 학습하도록 돕는 iPhone·iPad 앱 **"내 목소리"**의 지원 페이지예요.

- 🌐 지원 페이지: https://roachjbj-app.github.io/my-voice-support/
- 🔒 개인정보 처리방침: https://roachjbj-app.github.io/my-voice-support/privacy.html

## 문의하기
궁금한 점이나 문제가 있으면 [이슈](https://github.com/roachjbj-app/my-voice-support/issues/new)를 남겨 주세요.
**녹음 파일이나 개인 정보(이름, 연락처 등)는 올리지 말아 주세요.** 이 레포는 누구나 볼 수 있어요.

## 개인정보 요약
서버, 계정, 광고, 분석 도구가 없어요. 녹음은 기기에만 저장되고, 내가 직접 학습 패키지를 내보낼 때만 밖으로 나가요. 목소리를 흉내 내는 음성 합성 기능은 없어요. 이 앱은 의료 기기가 아니에요.

---
My Voice is an iOS app that helps people with dysarthria build a personal speech dataset and fine-tune their own speech-recognition model. No servers, no accounts, no analytics. For support, please [open an issue](https://github.com/roachjbj-app/my-voice-support/issues/new).
