개인정보 처리방침

내 목소리 · 시행일 2026년 10월 29일

"내 목소리"(이하 앱)는 말장애가 있는 사람이 자기 목소리로 음성인식 학습 데이터를 만들도록 돕는 앱입니다. 앱은 서버가 없고, 개인정보를 수집하거나 전송하지 않습니다.

1. 기기 안에만 저장하는 정보

정보용도
녹음한 음성 (WAV)학습 데이터
녹음한 문장, 사용자가 직접 넣은 문장학습 라벨
녹음 환경·컨디션·더듬음 표시, 기기 모델명학습 데이터 정리
앱 설정, 무작위 화자 ID앱 동작, 패키지 구분

이 정보는 앱 개발자를 포함한 누구에게도 자동으로 전송되지 않습니다. 계정, 광고, 분석 도구, 추적이 없습니다.

2. 사용자가 직접 내보낼 때

사용자가 "학습 패키지 만들기"를 누르면 위 정보를 ZIP 파일 하나로 묶습니다. 이 파일을 어디로 보낼지(파일 앱, Google Drive, 컴퓨터 등)는 사용자가 정하며, 보낸 곳의 약관과 개인정보 정책이 적용됩니다. 내보내기 전에 앱이 이 점을 다시 확인합니다.

3. 백업

기본적으로 기기 백업(iCloud 백업 등)에 포함될 수 있습니다. 설정에서 "녹음을 기기 백업에서 빼기"를 켜면 포함되지 않습니다.

4. 삭제

설정 → "모든 녹음과 내 문장 지우기"로 언제든 모두 지울 수 있고, 앱을 삭제해도 모두 지워집니다.

5. 마이크 권한

문장을 읽어 녹음할 때만 마이크를 사용합니다. 녹음 버튼을 누르지 않으면 녹음하지 않습니다.

6. 목소리 복제 금지

앱과 함께 제공하는 학습 도구는 음성 인식용입니다. 목소리를 흉내 내는 음성 합성 기능은 없습니다.

7. 의료 기기 아님

앱은 진단이나 치료를 하지 않는 소통 보조 도구입니다.

8. 문의

GitHub 이슈 · 지원 페이지

English summary

My Voice has no servers and collects no personal data. Voice recordings, sentence text, recording conditions, device model, settings and a random speaker ID are stored only on the device. Nothing is sent to the developer or any third party. There are no accounts, ads, analytics or tracking.

Data leaves the device only when the user explicitly creates a training package (ZIP) and chooses where to share it; the destination's terms then apply. The microphone is used only while the user records a sentence. Users can delete all data in Settings or by deleting the app. The training tools are for speech recognition only — no voice cloning. The app is not a medical device.

Effective date: October 29, 2026. Contact: GitHub Issues.
