데이터 저장

Supabase 계정을 통해 작품과 리비전이 동기화됩니다. 계정별 접근 권한을 적용합니다.

자주 묻는 질문

새 작품은 어떻게 작성하나요?

로그인 후 작품 화면에서 + 새 작품을 누르고 제목을 입력해 초안 만들기를 선택하세요. 편집 화면에서 본문을 입력해 저장할 수 있습니다.

초안과 개정본은 어떻게 구분되나요?

작품마다 리비전 이력을 보관합니다. 수정 후 저장을 누르면 현재 리비전을 갱신하고, 새 리비전을 누르면 새 버전으로 기록합니다. 이전 리비전도 확인할 수 있습니다.

글서랍에서 백업한 파일을 가져올 수 있나요?

네. 가져오기에서 지원하는 JSON 또는 ZIP 백업 파일을 선택하면 가져오기 전 분석 결과를 확인할 수 있습니다. 제목·본문이 같은 리비전은 제외하고, 본문 유사도 70% 이상인 작품을 같은 작품군으로 묶는 기능이 있습니다. 자동 분석 결과를 확인한 후 가져오세요.

회원가입 인증 메일이 도착하지 않아요.

스팸함과 전체 메일을 확인한 후 로그인 화면의 인증 메일 다시 보내기를 이용하세요. 발송 제한 메시지가 나오면 반복해서 요청하지 말고 제한이 해제된 뒤 다시 시도해 주세요.

iPhone과 iPad에서 같은 작품을 볼 수 있나요?

두 기기에서 동일한 글곳간 계정으로 로그인하고 인터넷에 연결하면 같은 클라우드 작품 기록을 사용할 수 있습니다.

작품집과 제출 기록은 어디서 보나요?

하단 작품집에서 저장된 작품집과 제출 당시 지정했던 리비전을 확인할 수 있습니다. 현재 앱의 작품집 화면은 조회 중심입니다.

백업은 어떻게 하나요?

백업을 눌러 JSON 백업 파일을 만들고 iOS 공유 메뉴로 내보낼 수 있습니다. 백업 형식에 따라 디카시 원본 사진이 포함되지 않을 수 있으므로 중요한 사진은 별도 보관해 주세요.

내 계정과 작품을 삭제하려면 어떻게 하나요?

앱의 설정 → 계정 영구 삭제에서 진행할 수 있습니다. 삭제는 되돌릴 수 없으므로 먼저 필요한 작품을 백업하세요. 기존 글서랍과 같은 계정을 사용하는 경우 기존 글서랍의 데이터에도 영향을 줄 수 있습니다.
